Une équipe entière, avec OpenRig.

OpenRig fait travailler plusieurs agents comme une équipe : un pilote, des développeurs, une revue. Ledge en est le poste de pilotage. Vous lancez l'équipe, vous la voyez s'organiser, et ses questions vous arrivent comme celles de n'importe quel agent.

Faites glisser pour voir tout l'écran.

Lancer
Depuis une spec enregistrée, un rig arrêté, ou en décrivant le besoin : l'operator propose l'équipe.
Régler
Le nombre de sièges par rôle, leur agent, leur modèle et leurs permissions, même quand le rig tourne.
Répondre
Les décisions et les questions de l'équipe arrivent dans « À toi », sur le PC comme sur le téléphone.
Garder la main
Chaque action affiche la commande rig qu'elle lance. Un instantané permet de revenir en arrière.

OpenRig s'installe à part. Ledge le pilote, il ne le remplace pas. Découvrir OpenRig

La demande arrive là où vous êtes.

Dans un terminal

ledge tui ouvre le même Ledge dans un onglet WSL, sur un serveur en SSH ou dans un volet tmux. Une touche suffit pour répondre.

En haut de l'écran

L'encoche, sur Windows. Une demande d'accord y arrive tout de suite, avec ses deux réponses. Le reste, Ledge le regroupe et vous le dit en une fois, sans une bulle par agent. Vous continuez à taper là où vous étiez.

Dans la poche

Une application à poser sur l'écran d'accueil, chiffrée de bout en bout. Décidez, suivez une session, lancez-en une, fusionnez une PR, menez vos rigs. Ce qui engage demande Face ID ou votre empreinte.

Rien sans votre clic.

Ledge propose, vous décidez. Et personne d'autre ne peut décider à votre place.

L'assistant lit, il n'agit pas
Il tourne en lecture seule. Chaque action passe par une carte que vous confirmez.
Tout reste chez vous
Le démon n'écoute que sur 127.0.0.1. Vos serveurs sont joints par votre SSH.
Le relais ne lit rien
Entre le PC et le téléphone ne passent que des messages chiffrés. Vous pouvez héberger le relais.
Un code à comparer
Un appareil n'accède à rien avant que vous ayez vérifié le même code à six chiffres sur les deux écrans.
Vos agents restent libres
Ledge s'ajoute à leurs hooks et rend toujours la main. Sans lui, vos sessions continuent comme avant.

Installez-vous.

Il vous faut Windows 10 ou 11 avec WSL2, Node 22.13 ou plus récent, Git et tmux, et au moins un agent déjà installé.

  1. 1

    Le démon, dans WSL

    npm i -g @paradow/ledge && ledge setup

    Branche vos agents et démarre le service.

  2. 2

    Ledge Desktop, sur Windows

    Télécharger pour Windows

    L'encoche et la fenêtre, une seule application. [LIEN DE TÉLÉCHARGEMENT]

  3. 3

    Votre première session

    ledge claude

    Ou « Nouvelle session » dans Ledge Desktop.

  • Ledge Desktop et l'encoche sont pour Windows. Le démon tourne sous Linux : WSL2 ou un serveur.
  • Une session lancée sans Ledge reste visible, en lecture seule.
  • Le téléphone agit sur le PC auquel il est lié, pas sur vos autres machines.
  • Le relais hébergé est sur invitation. Vous pouvez héberger le vôtre.
