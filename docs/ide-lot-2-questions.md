# Lot 2 de la refonte IDE : questions pour design-ux

Ce que la maquette (docs/mockups/ledge-ide-interactive.html) ne dessine pas. Aucun de ces états n'est inventé dans le code ; chacun attend une réponse.

1. **Logo de Cursor Agent (R9).** La maquette place un logo par fournisseur (Anthropic, OpenAI, OMP) dans l'onglet et l'en-tête de session. Cursor Agent n'en a pas. Quel signe pour ses sessions : une pastille neutre, ses initiales, ou son propre logo ?
2. **La ligne d'en-tête restante (R5).** La maquette ne place pas : le relais (handover), les étiquettes Story / Objectif, « N sous-agents », la pastille Navigateur, la puce terminal local / distant. Ils restent dans une ligne d'en-tête mince, masquée quand elle est vide. Est-ce le bon endroit, ou certains doivent-ils disparaître de l'onglet ?
3. **Onglet d'une machine hors ligne (reste du lot 1).** Quel texte porte un onglet dont la machine est hors ligne : seulement le point grisé, un mot (« hors ligne »), le nom de la machine ?
4. **Cadre vide du panneau du bas (reste du lot 1).** Que montre le panneau du bas quand il n'a aucun onglet : rien, une phrase d'invite, ou une action (« Ouvrir un terminal ») ?
