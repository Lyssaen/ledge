# L'île en haut de l'écran — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Use superpowers:subagent-driven-development only if the user chooses delegated execution. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer la poignée du bord gauche par une île centrée sur le bord supérieur de l'écran, d'où descendent la bulle, la liste et toutes les vues, avec ses congés concaves, son mode discret et ses deux réglages.

**Architecture:** La géométrie (`geometry.ts`) calcule désormais un `left` et pose tout à `top = 0` ; l'île compacte est une rangée horizontale. Le cadre natif (`frame.ts`, `bridge.ts`, `useNativeFrame.ts`, `main.rs`) gagne un `left` et le shell place la fenêtre à `(left, top)` dans la zone de travail de l'écran choisi. Les congés tournent d'un quart de tour, la poignée devient une rangée avec pastille « +n » et variante trait, la bulle est l'île qui s'étire. Le poller natif surveille la bande du bord supérieur et signale une fenêtre maximisée au premier plan pour le mode discret.

**Tech Stack:** TypeScript, React 19, Vitest + Testing Library (jsdom), Playwright 1.49, Tauri 2 (Rust, crate `windows` 0.58). Aucune dépendance nouvelle.

**Spec:** [L'île en haut de l'écran — design](../specs/2026-10-12-island-design.md). Maquette : [docs/mockups/ledge-island.html](../../mockups/ledge-island.html).

## Global Constraints

- Île compacte : 38 px de haut, 12 px de marge, mascotte 22, trait 1 × 16, compagnons 22 espacés de 8, 14 px de marge ; six compagnons au plus puis une pastille mono « +n » ; jamais plus de 300 px de large (spec §3).
- Mode discret : trait de 10 px, points 6 × 4 par session, six au plus, congés de 6 px ; redéployé par survol, `Ctrl+Alt+L`, une demande ou un tour terminé ; redevient trait 500 ms après le repli (spec §3).
- Congés : rayon 12 px (6 px pour le trait), jamais plus que la moitié de la largeur, chevauchement d'un pixel, couleur `--notch`, sans bordure (spec §3).
- Coins inférieurs : 22 px panneaux, 19 px île compacte, 6 px trait ; coins supérieurs droits (spec §3).
- Les vues gardent leurs largeurs : `listW` 380, `sessionW` 480, `readingW` 560, `readerW` 560 / `readerExpandedW` 800 ; hauteur max = zone de travail − `SIZES.margin` (spec §3). La bulle s'étire à 440 px (spec §2).
- Zone chaude : l'île plus une bande de 10 px le long du bord supérieur qui déborde de 40 px de chaque côté ; dwell 180 ms, leave 500 ms inchangés (spec §4).
- Réglages : « Position de l'île » (Centre · Décalée à gauche · Décalée à droite, défaut Centre, axe au quart de la largeur), « Mode discret sous une fenêtre » (interrupteur, défaut activé), « Taille de la poignée » devient « Taille de l'île » (spec §5). Clés localStorage : `ledge.islandPosition`, `ledge.discreet`. La clé `ledge.handleScale` ne change pas.
- Clavier et clic en dehors inchangés ; une session ouverte n'est jamais repliée par le survol (spec §4, §7).
- Pas de toolchain Rust sur cette machine : `main.rs` se relit à la main et se compile sur le tag `v*` (CI `release.yml`, `cargo test`). Le plan garde les changements Rust petits et testés par des fonctions pures.
- Écart assumé avec la maquette : la lune « Ne pas déranger » est dessinée à droite des compagnons (12 px) ; aucun autre élément visuel nouveau.

## Review Focus

- Zone de travail plus étroite que la vue (lecteur 800 px sur 700 px) : la vue se réduit à `screenW − 24` et `left` se cale à 0, le cadre ne sort jamais de l'écran → test dans la tâche 3.
- Position « Décalée à gauche » avec une île ou une vue plus large que le quart d'écran : `left` est borné à `[0, screenW − w]`, jamais négatif → test dans la tâche 3.
- Plus de six sessions dont une demande au-delà de la sixième : la demande passe devant et prend un slot, la pastille compte le reste → test dans la tâche 3.
- Barre des tâches en haut de l'écran : `top = 0` est celui de la zone de travail, le shell ajoute `area.y` ; une barre à gauche ajoute `area.x` au `left` → test Rust dans la tâche 11.
- Le trait du mode discret pendant qu'une bulle arrive ou qu'un panneau est ouvert : `strip` n'agit qu'en mode `handle`, la bulle et les vues gardent leur taille → test dans la tâche 3 et test de surface dans la tâche 9.

```ts
// apps/overlay/src/island.ts
/**
 * The island's two settings (spec 2026-10-12 §5): where its axis sits on the top edge, and whether it shrinks to a
 * strip under a maximised window. Both apply live; storage failures fall back to the defaults.
 */
export type { IslandPosition } from './surface/geometry';
import type { IslandPosition } from './surface/geometry';

export const ISLAND_POSITIONS: readonly IslandPosition[] = ['center', 'left', 'right'];
const POSITION_KEY = 'ledge.islandPosition';
const DISCREET_KEY = 'ledge.discreet';

export function loadIslandPosition(): IslandPosition {
  try {
    const v = localStorage.getItem(POSITION_KEY);
    return (ISLAND_POSITIONS as readonly string[]).includes(v ?? '') ? (v as IslandPosition) : 'center';
  } catch { return 'center'; }
}
export function saveIslandPosition(p: IslandPosition): void {
  try { localStorage.setItem(POSITION_KEY, p); } catch { /* storage unavailable: the in-memory value still applies */ }
}
/** On unless explicitly switched off. */
export function loadDiscreet(): boolean {
  try { return localStorage.getItem(DISCREET_KEY) !== '0'; } catch { return true; }
}
export function saveDiscreet(on: boolean): void {
  try { localStorage.setItem(DISCREET_KEY, on ? '1' : '0'); } catch { /* ignore */ }
}
```

```ts
// apps/overlay/src/surface/useDelayed.ts
import { useEffect, useState } from 'react';

/** `value` held true for `ms` ms: the discreet strip comes back 500 ms after the island folds, never at once. */
export function useDelayed(value: boolean, ms: number): boolean {
  const [on, setOn] = useState(false);
  useEffect(() => {
    if (!value) { setOn(false); return; }
    const t = setTimeout(() => setOn(true), ms);
    return () => clearTimeout(t);
  }, [value, ms]);
  return value && on;
}
```

```ts
// apps/overlay/src/surface/geometry.ts
export const SIZES = { bubbleW: 440, bubbleH: 128, listW: 380, sessionW: 480, readingW: 560, readerW: 560, readerExpandedW: 800, readerH: 760, rowH: 58, headerH: 72, footerH: 44, margin: 40, settingsH: 360, helpH: 420, launchH: 600, chatH: 560, emptyH: 200, groupH: 28, separatorH: 1 } as const;
/** The compact island, a row along the top edge (spec 2026-10-12 §3): margins, the Ledge mascot, the separator, the
 *  companions, the "+n" pill past six, the DND moon; and the discreet strip with one dot per session. */
export const ISLAND = { h: 38, padL: 12, padR: 14, resident: 22, sepGap: 8, companion: 22, gap: 8, max: 6, pill: 30, moon: 12, stripH: 10, stripPad: 10, dotW: 6, dotH: 4, dotGap: 4 } as const;
/** The surface's top + bottom border (border-box): added to a measured content height so nothing is clipped. None:
 *  the notch is borderless so it merges with the screen edge. */
export const SURFACE_BORDER = 0;
export const SURFACE_CHROME_Y = 2 * SURFACE_BORDER;
export type Mode = 'handle' | 'bubble' | 'list' | 'session' | 'settings' | 'help' | 'launch' | 'chat' | 'reader';
/** Where the island's axis sits on the top edge: the centre, or a quarter of the width from the left or the right. */
export type IslandPosition = 'center' | 'left' | 'right';
/** The resident's finished-chat notice: not a session id. */
export const LEDGE_ID = 'ledge';
/** The detail views that share the list's width and the DetailHeader: settings, help and the launch form. */
export const DETAIL_VIEWS: readonly Mode[] = ['settings', 'help', 'launch'];
const DETAIL_FALLBACK_H: Record<'settings' | 'help' | 'launch', number> = { settings: SIZES.settingsH, help: SIZES.helpH, launch: SIZES.launchH };
/** A companion's place in the island: `center` is its x on screen (real px). */
export interface Slot { id: string; size: number; center: number }
export interface Layout { left: number; top: number; w: number; h: number; slots: Slot[]; handle: { left: number; w: number; h: number } }

/** The island shows asks first, then the others in list order (stable). */
export function islandOrder<T extends { pending: boolean }>(bots: T[]): T[] {
  return [...bots.filter(b => b.pending), ...bots.filter(b => !b.pending)];
}
/** The compact island's width for `n` sessions: six companions at most, then the "+n" pill; the DND moon when on. */
export function islandWidth(n: number, dnd = false): number {
  const moon = dnd ? ISLAND.gap + ISLAND.moon : 0;
  if (n === 0) return ISLAND.padL + ISLAND.resident + moon + ISLAND.padR;
  const shown = Math.min(n, ISLAND.max);
  return ISLAND.padL + ISLAND.resident + ISLAND.sepGap + SIZES.separatorH + ISLAND.sepGap + shown * ISLAND.companion + (shown - 1) * ISLAND.gap + (n > ISLAND.max ? ISLAND.gap + ISLAND.pill : 0) + moon + ISLAND.padR;
}
/** The discreet strip's width: one dot per session (six at most), never narrower than the bare island. */
export function stripWidth(n: number): number {
  const shown = Math.min(n, ISLAND.max);
  return Math.max(islandWidth(0), 2 * ISLAND.stripPad + shown * ISLAND.dotW + Math.max(0, shown - 1) * ISLAND.dotGap);
}
export const islandAxis = (screenW: number, position: IslandPosition = 'center'): number =>
  position === 'left' ? screenW / 4 : position === 'right' ? (3 * screenW) / 4 : screenW / 2;

const clamp = (v: number, lo: number, hi: number) => Math.max(lo, Math.min(hi, v));

/** `detailH` is the measured height of the settings or help view (the fixed sizes are fallbacks). `listExtraH` is the extra height of an expanded (focused) list row. `bubbleH` is the measured bubble height; `SIZES.bubbleH` is only the fallback before the first measurement. `strip` draws the discreet strip instead of the compact island (handle mode only). */
export interface LayoutInput { bots: Array<{ id: string; pending: boolean }>; mode: Mode; screenH: number; screenW: number; position?: IslandPosition; strip?: boolean; dnd?: boolean; readerExpanded?: boolean; bubbleH?: number; sessionH?: number; reading?: boolean; listExtraH?: number; groups?: number; detailH?: number; /** Extra height of the ask field above the list rows (`ASK_H`). */ askH?: number }

/** Everything hangs from the top edge of the work area, centred on the island's axis; `left` is clamped into the screen. */
export function layout(input: LayoutInput): Layout {
  const { bots, mode, screenH, screenW } = input;
  const n = bots.length;
  const maxH = screenH - SIZES.margin;
  const axis = islandAxis(screenW, input.position);
  const place = (w: number) => clamp(Math.round(axis - w / 2), 0, Math.max(0, screenW - w));
  const strip = mode === 'handle' && !!input.strip;
  const handleW = strip ? stripWidth(n) : islandWidth(n, input.dnd);
  const handle = { left: place(handleW), w: handleW, h: strip ? ISLAND.stripH : ISLAND.h };
  const slots: Slot[] = [];
  let x = handle.left + ISLAND.padL + ISLAND.resident + ISLAND.sepGap + SIZES.separatorH + ISLAND.sepGap;
  for (const b of islandOrder(bots).slice(0, ISLAND.max)) { slots.push({ id: b.id, size: ISLAND.companion, center: x + ISLAND.companion / 2 }); x += ISLAND.companion + ISLAND.gap; }
  const view = (w: number, h: number): Layout => ({ left: place(w), top: 0, w, h: Math.min(maxH, h), slots, handle });
  if (mode === 'handle') return { left: handle.left, top: 0, w: handleW, h: handle.h, slots, handle };
  if (mode === 'bubble') return view(SIZES.bubbleW, input.bubbleH ?? SIZES.bubbleH);
  // The native frame adds a small shadow outside this width.
  if (mode === 'reader') return view(Math.min(input.readerExpanded ? SIZES.readerExpandedW : SIZES.readerW, Math.max(0, screenW - 24)), SIZES.readerH);
  if (mode === 'chat') return view(SIZES.sessionW, input.detailH ?? SIZES.chatH);
  if (mode === 'settings' || mode === 'help' || mode === 'launch') return view(SIZES.listW, input.detailH ?? DETAIL_FALLBACK_H[mode]);
  // An empty list shows the empty state (a bot, two lines, a button) instead of rows.
  const rowsH = n === 0 ? SIZES.emptyH : 16 + n * SIZES.rowH + (input.groups ?? 0) * SIZES.groupH + (input.listExtraH ?? 0);
  if (mode === 'list') return view(SIZES.listW, SIZES.headerH + rowsH + (input.askH ?? 0) + SIZES.footerH + SURFACE_CHROME_Y);
  return view(input.reading ? SIZES.readingW : SIZES.sessionW, input.sessionH ?? 480);
}

/**
 * The layout under the two UI scales, in real (logical) px. The island (its slots and the handle-mode surface) is
 * laid out in a screen of `screenW / handle` x `screenH / handle` units and multiplied by `handle`; the opened views
 * in a screen divided by `panel`, multiplied by `panel`. Heights in the input are base content heights plus `SURFACE_CHROME_Y`.
 */
export function scaledLayout(input: LayoutInput, scales: { handle: number; panel: number }): Layout {
  const hs = scales.handle, ps = scales.panel;
  const hl = layout({ ...input, mode: 'handle', screenH: input.screenH / hs, screenW: input.screenW / hs });
  const slots = hl.slots.map(s => ({ id: s.id, size: s.size * hs, center: s.center * hs }));
  const handle = { left: hl.handle.left * hs, w: hl.handle.w * hs, h: hl.handle.h * hs };
  if (input.mode === 'handle') return { left: hl.left * hs, top: 0, w: hl.w * hs, h: hl.h * hs, slots, handle };
  const pl = layout({ ...input, screenH: input.screenH / ps, screenW: input.screenW / ps });
  // The surface's border is 1 real px whatever the scale: only the content inside it is zoomed.
  return { left: pl.left * ps, top: 0, w: pl.w * ps, h: (pl.h - SURFACE_CHROME_Y) * ps + SURFACE_CHROME_Y, slots, handle };
}
```

```ts
// apps/overlay/src/surface/frame.ts
import type { Frame } from '../tauri/bridge';

/** Something drawn at a page position (logical px; the page's axes are the work area's). */
export interface Box { left: number; top: number; w: number; h: number }
/** Room around the drawn boxes for the overlay shadow (it falls sideways and mostly downward; nothing is above the top edge). */
export const FRAME_PAD = { left: 16, right: 16, bottom: 24 } as const;

/** The native window: the bounding box of the surface and every visible extra (fillets, status line, unread say,
 *  coachmark), padded for the shadow and clamped to the work area. Integer px for the shell. */
export function frameOf(surface: Box, extras: Box[], screen: { w: number; h: number }): Frame {
  const boxes: Box[] = [surface, ...extras];
  const left = Math.max(0, Math.floor(Math.min(...boxes.map(b => b.left)) - FRAME_PAD.left));
  const right = Math.min(screen.w, Math.ceil(Math.max(...boxes.map(b => b.left + b.w)) + FRAME_PAD.right));
  const top = Math.max(0, Math.floor(Math.min(...boxes.map(b => b.top))));
  const bottom = Math.min(screen.h, Math.ceil(Math.max(...boxes.map(b => b.top + b.h)) + FRAME_PAD.bottom));
  return { left, top, w: Math.max(1, right - left), h: Math.max(1, bottom - top) };
}

/** The smallest frame holding both: the window while the surface animates from one to the other. */
export function unionFrame(a: Frame, b: Frame): Frame {
  const left = Math.min(a.left, b.left), top = Math.min(a.top, b.top);
  return { left, top, w: Math.max(a.left + a.w, b.left + b.w) - left, h: Math.max(a.top + a.h, b.top + b.h) - top };
}

export const containsFrame = (outer: Frame, inner: Frame) =>
  outer.left <= inner.left && outer.top <= inner.top && outer.left + outer.w >= inner.left + inner.w && outer.top + outer.h >= inner.top + inner.h;
```

```ts
export const FOREGROUND_EVENT = 'ledge://foreground';

/** A frame in CSS px to monitor px under `zoom`: the edges are rounded outward so the window always holds the drawing. */
export function toMonitorFrame(f: Frame, zoom = 1): Frame {
  if (zoom === 1) return f;
  const left = Math.floor(f.left * zoom), top = Math.floor(f.top * zoom);
  return { left, top, w: Math.max(1, Math.ceil((f.left + f.w) * zoom) - left), h: Math.max(1, Math.ceil((f.top + f.h) * zoom) - top) };
}

export function setFrame(f: Frame, zoom = 1): Promise<boolean> {
  if (!inTauri()) return Promise.resolve(false);
  const m = toMonitorFrame(f, zoom);
  const key = `${m.left}:${m.top}:${m.w}:${m.h}`;
  if (key === lastFrame) return frameChain.then(() => lastFrame === key);
  lastFrame = key;
  const run = frameChain.then(() => invoke('set_frame', { left: m.left, top: m.top, width: m.w, height: m.h })).then(() => true, () => { if (lastFrame === key) lastFrame = ''; return false; });
  frameChain = run;
  return run;
}

let lastHot = '';
/** The island's x range in logical px: the shell's cursor poller watches the 10 px band along the top edge around it. */
export function setHotZone(left: number, width: number): void {
  if (!inTauri()) return;
  const key = `${left}:${width}`;
  if (key === lastHot) return;
  lastHot = key;
  invoke('set_hot_zone', { left, width }).catch(() => { if (lastHot === key) lastHot = ''; });
}

/** Whether a maximised or full-screen window holds the foreground on the island's monitor (the discreet strip). In the
 *  browser, a `ledge:foreground` CustomEvent on `window` (dev previews and e2e) stands in for the shell. */
export function onForegroundCovered(fn: (covered: boolean) => void): () => void {
  if (!inTauri()) {
    const h = (e: Event) => fn(!!(e as CustomEvent<{ covered: boolean }>).detail?.covered);
    window.addEventListener('ledge:foreground', h);
    return () => window.removeEventListener('ledge:foreground', h);
  }
  let off = () => {}; let disposed = false;
  void listen<{ covered: boolean }>(FOREGROUND_EVENT, e => { if (!disposed) fn(e.payload.covered); }).then(un => {
    off = un;
    if (disposed) un();
  }).catch(() => {});
  return () => { disposed = true; off(); };
}
```

```ts
export interface PageOffset { left: number; top: number }
const NO_OFFSET: PageOffset = { left: 0, top: 0 };

export function useNativeFrame(frame: Frame, settleMs: number, zoom = 1): PageOffset {
  const [offset, setOffset] = useState<PageOffset>(NO_OFFSET);
  const applied = useRef<Frame | null>(null);
  const wanted = useRef({ frame, zoom });
  const cancelCommit = useRef<() => void>(() => {});
  const settle = useRef<{ timer?: ReturnType<typeof setTimeout>; cancel?: () => void }>({});
  const key = `${frame.left}:${frame.top}:${frame.w}:${frame.h}@${zoom}`;
  useLayoutEffect(() => {
    wanted.current = { frame, zoom };
    const clearSettle = () => { clearTimeout(settle.current.timer); settle.current.cancel?.(); settle.current = {}; };
    const apply = (f: Frame, z: number, inRender: boolean) => {
      applied.current = f;
      if (isTauri()) {
        const m = toMonitorFrame(f, z); const next = { left: m.left / z, top: m.top / z };
        const set = () => setOffset(o => (o.left === next.left && o.top === next.top ? o : next));
        if (inRender) set(); else flushSync(set);
      }
      void setFrame(f, z);
    };
    // … the rest of the effect is unchanged (commit, union, settle, afterPaint) …
  }, [key, settleMs]);
  useEffect(() => () => { cancelCommit.current(); clearTimeout(settle.current.timer); settle.current.cancel?.(); }, []);
  return offset;
}
```

```tsx
import type { CSSProperties } from 'react';

/** The radius of the concave fillets joining the island to the top screen edge (spec 2026-10-12 §3). */
export const SHOULDER_R = 12;
/** The discreet strip's smaller fillets. */
export const STRIP_SHOULDER_R = 6;
/** How far each fillet reaches into the surface, in the notch colour. */
const OVERLAP = 1;
/** The fillet radius for a surface of width `w`: never wider than half of it. */
export const shoulderR = (w: number, strip = false) => Math.min(strip ? STRIP_SHOULDER_R : SHOULDER_R, Math.floor(w / 2));

/** The two concave fillets either side of the island where it leaves the top screen edge: the notch flows out of the
 *  edge instead of starting at a right angle. Filled with the notch colour and borderless like the surface, they follow
 *  its left and width with the same transition. */
export function Shoulders({ left, w, strip = false, transition, opacity }: { left: number; w: number; strip?: boolean; transition: string; opacity: number }) {
  const r = shoulderR(w, strip);
  if (r <= 0) return null;
  // Along the screen edge (tangent to it) OVERLAP px into the island, down the island's edge (tangent to it) to the
  // fillet's foot, then back to the corner along the arc. Meeting the island on a shared edge would leave a seam at a
  // fractional display scale (150 %): both edges land mid-pixel, each covers half the column and the desktop shows through.
  const fill = `M0,0 H${r + OVERLAP} V${r} H${r} A${r},${r} 0 0 0 0,0 Z`;
  const box: CSSProperties = { position: 'absolute', top: 0, width: r + OVERLAP, height: r, pointerEvents: 'none', opacity };
  const svg = (flip: boolean) => (
    <svg width={r + OVERLAP} height={r} viewBox={`0 0 ${r + OVERLAP} ${r}`} style={{ display: 'block', transform: flip ? 'scaleX(-1)' : undefined }}>
      <path d={fill} fill="var(--notch)" />
    </svg>
  );
  return (
    <>
      <div data-shoulder="left" aria-hidden style={{ ...box, left: left - r, transition }}>{svg(false)}</div>
      <div data-shoulder="right" aria-hidden style={{ ...box, left: left + w - OVERLAP, transition }}>{svg(true)}</div>
    </>
  );
```

```rust
pub fn frame_rect(area: Area, left: i32, top: i32, width: u32, height: u32) -> (i32, i32, u32, u32) {

/// True when the logical cursor `(x, y)` is in the band along the top edge around the island `hot = (left, width)`,
/// within `NEAR_REACH` of it: the hot band that opens the list and the region the mascot's gaze follows.
pub fn cursor_near(hot: Option<(i32, u32)>, x: f64, y: f64) -> bool {
    let Some((left, width)) = hot else { return false };
    y >= 0.0 && y <= NEAR_REACH && x >= left as f64 - NEAR_REACH && x <= (left + width as i32) as f64 + NEAR_REACH
}
```
