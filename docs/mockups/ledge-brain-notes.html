Cerveau de Ledge : les écrans

Lot 4 de la spec du cerveau. Aujourd'hui, une proposition de note arrive comme une décision en texte libre (« oui », « non », « oui : ton texte »). Ces planches la remplacent par des boutons, ajoutent une page Réglages › Notes et une carte du chat pour « retiens que… ». Les textes sont ceux que l'interface afficherait.

1. « À toi » sur le desktop : une proposition de note

Même place que les décisions des sessions, dans « Le point ». Le fait est cité tel qu'il sera écrit ; la source dit d'où la session le tient. « Modifier » ouvre le texte avant l'ajout. Rien ne s'écrit avant un clic sur « Ajouter ».

3. Réglages › Notes

Une page de lecture : ce que Ledge sait de tes notes et ce qu'il en propose. Le texte d'une note se change dans le fichier (« Ouvrir » l'affiche dans le lecteur Markdown de Ledge). Deux gestes seulement écrivent : « Vérifiée aujourd'hui » met checked à la date du jour, « Effacer le signalement » retire « à revoir ».

« Chat seulement », les projets et la date se règlent dans l'en-tête de la note (scope, projects, checked). Une note devient « ancienne » après 60 jours sans vérification ni modification.

4. Le chat : « retiens que… »

Une nouvelle action du chat, note.add, sur la carte générique : l'utilisateur dit un fait et demande de le garder ; Ledge choisit la note d'après l'index, ou demande laquelle. « Appliquer » écrit, comme pour une proposition validée, signé « dit par l'utilisateur ».

Retiens que Legion a maintenant 64 Go de RAM.

Je l'ajoute à ta note machines, qui décrit Legion (vérifiée le 01/11).

À trancher sur ces planches

  1. Les boutons de la proposition : « Ajouter », « Modifier », « Refuser » ; du signalement : « Marquer à revoir », « Ignorer ».
  2. Le téléphone répond sur place, avec la vérification de l'appareil, au lieu de passer par le champ du chat.
  3. Réglages › Notes reste une page de lecture, avec deux seuls gestes qui écrivent : « Vérifiée aujourd'hui » et « Effacer le signalement ».
  4. La carte note.add du chat, pour « retiens que… ».
