Maquette de référence pour la tâche Ledge t585479 (td5205e). Écrans de l'app mobile (apps/mobile), largeur 360 px, gouttière 16 px, tokens de @ledge/ui. Les encadrés jaunes sont des notes : ils ne s'affichent pas dans l'app.

La liste montre Fermeture… puis Terminée · 18:42.

Sur la page de la session seulement, à droite du bouton Terminal. Pas dans la liste : chaque ligne est un lien vers la session, et un geste de balayage ne se découvre pas et ne se fait pas au clavier.

6. Spécification pour le dev

Ce qui manque aujourd'hui (protocole et daemon)

  • Message téléphone → PC session.close { op, id, assertion }, défi confirm.prepare { purpose: 'close', id } (aujourd'hui close ne vise qu'une carte, par qid). Le PC répond how: 'exit' | 'killed' et réutilise closeForCard pour partager une fermeture déjà en cours.
  • Message session.resume { op, id, assertion }, défi purpose: 'act', id (comme l'action session.resume du registre).
  • PhoneSession : readOnly: true pour une session hook_only (le téléphone ne le sait aujourd'hui qu'après un refus), et exitedAt pour l'heure de la liste.
  • Une capacité du daemon (ex. daemon.sessionClose) : un PC plus ancien → pas de bouton Fermer ni Reprendre.

Valeurs

  • Boutons : buttonClass({ variant: 'primary', block: true }) et buttonClass({ block: true }) (48 px de haut) ; bouton icône 44 × 44 ; Réessayer en size: 'sm' (44 px).
  • Feuille : Sheet existante (rayon 28 px, gouttière 20 px, gap-4), titre text-heading (21 px), corps text-body text-muted, note text-small text-muted.
  • Encadrés : Notice tone="warning" ; pied de page : la ligne d'état existante de Reply (point de 6 px ou spinner 12 px, text-meta).
  • Carte « Session terminée » : rounded-card border border-line bg-surface p-4 gap-2.5.

Accessibilité

  • Bouton Fermer : aria-label et title « Fermer Nova » ; pendant la fermeture aria-disabled et « Fermeture de Nova en cours ».
  • Feuille : role="dialog", aria-labelledby le titre, focus sur la feuille à l'ouverture, Échap et le voile ferment (useDialog). Ordre de tabulation : bouton principal, Annuler.
  • Erreurs en role="alert", suivi en role="status" ; le spinner est aria-hidden et le texte dit l'état ; pas d'animation avec prefers-reduced-motion.
  • L'état ne passe jamais par la seule couleur : chaque étiquette a son mot.

Critères d'acceptation

  1. Sur une session libre lancée par Ledge, Fermer → Face ID → la session passe « Terminée » sur le téléphone et sur le PC, sa conversation se reprend.
  2. Sur une session au travail avec une autorisation en attente, la feuille montre les deux lignes de 2b ; après fermeture, l'autorisation est refusée.
  3. Annuler, Échap, le voile ou une vérification annulée n'envoient rien.
  4. PC injoignable : la feuille montre 2d ; rien n'est envoyé.
  5. Session démarrée hors de Ledge, ou terminée : pas de bouton Fermer.
  6. Pendant la fermeture, la liste montre « Fermeture… » et le bouton Fermer est inactif ; un deuxième envoi est impossible.
  7. Un refus du PC montre l'encadré de 3c avec le bon texte, et le brouillon du champ est conservé.
  8. Depuis 3b, Reprendre → Face ID → le champ de saisie revient quand l'agent est relancé.
  9. Lecteur d'écran (VoiceOver / TalkBack) : chaque bouton est nommé, la feuille est annoncée par son titre, les changements d'état sont annoncés.
