À essayer. Tout ce qui ressemble à un bouton agit. Quelques pistes :

Explorateur : clic ouvre, Ctrl+clic à droite, clic droit = actions Glisser un onglet vers un autre groupe ou à droite Carré à gauche des onglets : lier le groupe (violet, vert d'eau) + d'un groupe ou N : Nouvelle session (fenêtre modale) Vue Rigs › kernel : operator, advisor, queue worker Vue Rigs : clic sur un rig = sa topologie en onglet Icône flèche : détacher le groupe dans une fenêtre Y / N sur Pim, répondre à dev-front Écrire à un agent : Entrée Modèle sous la réponse : le changer Barre d'état : limites d'usage Réglages › Espace de travail : chaque option agit OpenRig : arrêter, redémarrer, ± sièges Dispositions : appliquer, enregistrer Ctrl K palette · Ctrl J panneau du bas · Ctrl / panneau de droite · Ctrl \ diviser
