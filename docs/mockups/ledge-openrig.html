« + Lancer un rig… » ouvre ce formulaire à la place de la page. On part d'une spec (bibliothèque OpenRig, mes specs, un fichier du projet ou un bundle GitHub), on choisit le projet, la machine et le nom, puis on ajuste le nombre de sièges par rôle. Ledge écrit la spec résultante (aperçu à droite), la fait vérifier par rig up --plan, puis lance. « Enregistrer dans mes specs » la garde pour la prochaine fois.

Où vivent les specs
  • Bibliothèque OpenRig : livrée avec OpenRig (starter, factory, code-review…), en lecture seule.
  • Mes specs : ~/.openrig/specs/ sur la machine, via rig specs add.
  • Fichier du projet : un rig.yaml versionné dans le dépôt, ex. .openrig/rig.yaml.
  • Bundle GitHub : un lien vers un .rigbundle publié.

« ± Sièges » sur un rig en marche : les mêmes compteurs par rôle, appliqués sans arrêter le rig. Chaque nouveau siège copie le premier de son rôle (agent, harnais, modèle) et reçoit son lien de délégation. Les sièges existants continuent leur travail. Baisser un compteur retire les derniers sièges, avec la même confirmation qu'un arrêt s'ils travaillent.
