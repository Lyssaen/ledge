Fil de session

Replier, jamais tronquer

  • Chaque élément (outil, diff, permission, message envoyé / reçu, notice) se replie à la largeur réelle, comptée en cellules : un emoji ou un caractère comme 日 en vaut deux.
  • Retrait suspendu : la suite s'aligne sous le texte, pas sous l'icône. La durée et les +n −n restent à droite de la 1re ligne.
  • Plafond par élément : outil 3 lignes, message 3, erreur 3, notice 2, demande 4 ; au-delà … +n. espace (déplier) montre tout.
  • Diff : chaque ligne repliée, la suite marquée ↪ ; toujours 30 lignes par fichier au plus.
  • Un tour replié (▸) reste sur une ligne : c'est un résumé.
  • Spinner : seule la ligne en cours se redessine, à largeur fixe. Durée : 8,4 s, puis 12 s, puis 1 min 04.
  • Défilement : un indicateur dans la bordure basse (↑ 18 plus haut · ↓ 9 · G fin), absent quand on suit le bas.

Saisie

Un champ multi-ligne avec un curseur

  • Le champ grandit avec le texte, jusqu'à 6 lignes en 80×24 (8 en 120×32), puis défile, avec son indicateur dans la bordure.
  • Curseur en bloc inversé : ← →, ctrl ← → / alt ← → par mot, home end (ctrl a ctrl e), ↑ ↓ d'une ligne à l'autre, suppr, ctrl w mot précédent, ctrl u tout effacer (comme aujourd'hui).
  • ↵ envoie toujours. Nouvelle ligne : alt ↵ partout, maj ↵ quand le terminal la distingue, ctrl j en secours.
  • Collage : les retours à la ligne restent des retours à la ligne, sans envoyer ; plus de ⏎.
  • Historique : ↑ sur la 1re ligne (ou champ vide) remonte ce qui a été envoyé ; ↓ redescend jusqu'au brouillon, intact. Ask garde ses questions ; une session, ses réponses.
  • Le titre dit à qui l'on écrit : « Répondre à Otto », « Refuser en expliquant à Otto ».
  • Le brouillon d'une session survit à esc, à ctrl c et au changement d'écran ; il reste affiché, estompé, dans « Écrire ».

Le parseur est celui de packages/ui (remark + gfm) ; la TUI ne fait que convertir son arbre en lignes. Pendant le stream, le rendu suit ; un bloc de code pas encore fermé s'affiche déjà en bloc. En ASCII : • → -, │ → |.

Demander à Ledge

Défiler comme dans le fil

  • tab fait le tour : Question → cartes → Conversation. Dans la conversation, les touches du fil : j k ↑ ↓, PgUp PgDn, G ; esc rend la main à la question.
  • PgUp PgDn marchent aussi depuis le champ, sans le quitter (↑ ↓ y servent à l'historique).
  • Même indicateur que le fil, dans la bordure basse.
  • Une réponse qui s'écrit pendant la lecture ne fait pas sauter la vue : ↓ Ledge répond · G pour suivre.
  • La barre de touches suit le focus : « s enregistrer l'équipe » seulement sur une carte d'équipe.

Ctrl+N, Ctrl+C

Ne rien perdre par réflexe

  • ctrl n ouvre une confirmation à la place du champ. « Garder » est le choix par défaut (n, esc) ; y efface. Le brouillon reste.
  • ctrl c, dans l'ordre : une réponse s'écrit → l'arrêter (inchangé) ; un brouillon → ne quitte pas, une ligne jaune propose ctrl c encore, dans les 2 s, pour quitter quand même ; sinon → quitter.
  • Dans une session en saisie, ctrl c sort du champ en gardant le brouillon (inchangé), qui reste visible.

Redimensionnement

Ce qui reste visible

  • Par ordre de priorité : la demande en attente (jamais coupée), le champ (3 lignes au plus sous 24 rangées), la barre d'état (fil d'Ariane raccourci, puis retiré) ; le fil prend le reste, 3 lignes au moins.
  • Le défilement est recadré sur l'élément lu : ce qui était en haut reste en haut, même si le repli change le nombre de lignes.
  • Barre de touches : elles tombent par priorité ; ? « aide » (toutes les touches) reste toujours.
  • Sous 60×16 : un écran « Fenêtre trop petite » avec la taille actuelle ; rien n'est perdu, le brouillon reste.

Terminal clair

La palette est figée pour un fond sombre

theme.ts écrit le texte en #e6e0dc et la barre d'état sur #1f1d1b : sur un terminal clair, le texte disparaît (voir « Terminal : clair » + « Actuel »). Proposition : une seconde palette, choisie d'après le fond (COLORFGBG ou requête OSC 11), et un réglage Thème : auto / sombre / clair dans Réglages.
