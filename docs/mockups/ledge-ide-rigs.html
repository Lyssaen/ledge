Ledge IDE — Rigs sous un seul bouton
Ledge · IDE, prototype interactif données d'exemple · rien ne quitte la page

À essayer. Tout ce qui ressemble à un bouton agit. Quelques pistes :

Explorateur : clic ouvre, Ctrl+clic à droite, clic droit = actions Glisser un onglet vers un autre groupe ou à droite Carré à gauche des onglets : lier le groupe (violet, vert d'eau) + d'un groupe ou N : Nouvelle session (fenêtre modale) Vue Rigs › kernel : operator, advisor, queue worker Vue Rigs : clic sur un rig = sa vue Rig (topologie + réglages) · le bouton Lancer ouvre la fenêtre de lancement Glisser un onglet hors de la fenêtre : nouvelle fenêtre ; le glisser dans un groupe le ramène Y / N sur Pim, répondre à dev-front Barre d'activité › MR et PR : pipelines GitHub et GitLab, relancer, fusionner, faire corriger par l'agent Clic droit sur un onglet (ou Ctrl+`) : basculer fil ⇄ terminal, role.md, Cursor, fermer Écrire à un agent : Entrée Modèle sous la réponse : le changer Barre d'état : limites d'usage Réglages › Espace de travail : chaque option agit OpenRig : arrêter, redémarrer, ± sièges Barre d'état › disposition : appliquer, enregistrer Barre latérale : « Réduire », glisser son bord, Ctrl+B Terminal du panneau du bas : se glisse comme un onglet Bas d'onglet, tout à droite : +N −N ouvre les modifications à côté (rien si zéro modification) Vue À toi › « Page » : la page À toi (l'ancien Accueil) dans une nouvelle fenêtre Vue Projets › Archives : l'historique des sessions, comme aujourd'hui Ctrl K palette · Ctrl J panneau du bas · Ctrl / panneau de droite · Ctrl \ diviser
